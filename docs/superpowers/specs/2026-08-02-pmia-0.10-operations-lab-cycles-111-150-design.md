## Architectural decision

Operations Lab is a dashboard-local, metadata-only projection. It does not persist navigation, send runtime commands, focus provider pages, store interview content, or become another transport/recovery owner. The feature is split into:

- `operations-lab-model.js`: forty content-free capability records across ten views.
- `render-operations-lab.js`: bounded semantic renderer.
- `operations-lab-controller.js`: local view/scenario state and keyboard tab behavior.
- `operations-lab-content-audit.js`: deterministic privacy audit.
- `dashboard-snapshot-sync.js`: checked full/delta/heartbeat synchronization.

## Interaction model

The Lab appears inside Assist as one card. Ten preloaded local tabs use `role=tablist`, `role=tab`, `aria-selected`, `aria-controls`, and arrow/Home/End movement. The selected view renders four bounded cards. A local scenario selector offers Current, Service-worker restart, Receiver reload, Provider drift, and Network loss. Scenario selection changes only the derived explanation and never invokes a runtime command.
