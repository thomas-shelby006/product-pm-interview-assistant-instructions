# PMIA Runtime 0.5 Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove avoidable blocking from PMIA preview and final-delivery paths while preserving authoritative provider boundaries and durable recovery.

**Architecture:** Keep the proven extension-only preview/commit split. Make previews in-memory and latest-only, make final submission precede telemetry, replace the fixed submit delay with bounded provider readiness, and strengthen voice-state gating for Claude press-and-hold recording.

**Tech Stack:** JavaScript ES modules, Chrome Manifest V3, Node.js built-in test runner, AutoHotkey v2 validation.

## Global Constraints

- Do not modify or delete legacy launchers, Tampermonkey scripts, historical archives, or old ZIP files.
- Do not install dependencies.
- Do not call provider APIs or persist cookies.
- Preserve durable final idempotency and latest-only recovery.
- Preview delivery must remain disposable and must never queue.
- Use TDD for every behavior change.
- Keep changes limited to the extension runtime, tests, manifest/version, and active runtime documentation.

- [ ] **Step 3: Implement the scheduler and entry wiring**

```js
export function createLatestPreviewScheduler({ send, scheduleMicrotask = queueMicrotask }) {
  let queued = null;
  let scheduled = false;
  let stopped = false;
  const flush = async () => {
    scheduled = false;
    if (stopped || !queued) return false;
    const candidate = queued;
    queued = null;
    return Boolean(await send(candidate));
  };
  return {
    push(candidate) {
      if (stopped) return false;
      queued = candidate;
      if (!scheduled) {
        scheduled = true;
        scheduleMicrotask(flush);
      }
      return true;
    },
    flush,
    disconnect() { stopped = true; queued = null; }
  };
}
```

In `entry.js`, initialize preview sequence at zero in memory, remove preview session-storage reads/writes, and route all provider preview callbacks through `previewScheduler.push`.

if (!adapter.setComposerText(text)) return false;
for (let check = 0; check <= maxSubmitChecks; check += 1) {
  if (deliveryId !== latestDeliveryId) return false;
  if (adapter.composerContains(text) && (adapter.canSubmit() || check === maxSubmitChecks)) {
