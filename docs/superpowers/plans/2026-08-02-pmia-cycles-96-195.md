# PMIA Cycles 96-195: Live Operations and Reliability Plan

**Objective:** Extend the verified lossless PMIA runtime with two major 50-cycle phases. Phase A improves the operator's live mock-interview experience. Phase B hardens persistence, transport, browser lifecycle, provider adaptation, performance, and release evidence.

**Fixed authorities:** DeliveryLedger owns final durability; sender outbox owns pre-persistence retention; contiguous sequence admission owns ordering; receiver batch runtime owns provider submission; rendered receiver turns own delivery proof; Runtime Pilot state owns safe operational metadata.

**Non-goals:** No prompt redesign program, no provider private APIs, no focus stealing, no normal-profile mutation, no second transport, no disk-backed sensitive state, and no silent loss or latest-only eviction.

**Execution:** Write regression contracts with each cycle. Implement Cycles 96-145, then run one complete automated and isolated-browser gate. Implement Cycles 146-195 on that verified base, then run the final gate, evidence manifest, cleanup audit, and technical HTML update.

**Cycle contract:** Every cycle contains (1) a bug or failure-mode correction, (2) a user-facing live-interview capability, and (3) an owning-boundary implementation improvement.
