# PMIA 0.7 Reliability and Coherence Implementation Plan

> **For agentic workers:** Execute this plan task-by-task in the isolated worktree. Tests are written during development but are run only once in the final consolidated gate, per the user constraint.

**Goal:** Ship a safer, more coherent PM mock-interview runtime with ephemeral session state, deterministic cleanup and recovery, and richer review exports.

**Architecture:** Keep the existing AutoHotkey + Manifest V3 dual-provider design. Add focused shared modules for session log storage and safe session-context parsing, then make the background service worker own lifecycle orchestration.

**Tech Stack:** AutoHotkey v2, Manifest V3 JavaScript modules, Node.js built-in test runner, PowerShell validation.

## Global Constraints

- Original checkout remains unchanged.
- Legacy and archived files remain preserved.
- No intermediate test, build, validation, or browser run.
- One consolidated verification gate at the end.
- No browser mutation unless final evidence requires it.
