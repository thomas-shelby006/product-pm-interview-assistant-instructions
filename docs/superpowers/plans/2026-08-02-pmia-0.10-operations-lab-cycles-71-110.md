> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete twenty additional resilience fixes and twenty user-facing Operations Lab capabilities without changing PMIA’s authoritative ownership boundaries.

**Architecture:** Existing focused modules own all mechanics. The Operations Lab is one metadata-only Assist projection with dashboard-local navigation and recovery-scenario selection. Regression contracts are written during implementation and executed only after all source work is complete.

**Tech Stack:** JavaScript ES modules, Chrome Manifest V3, session storage, AutoHotkey v2, Node test runner, PowerShell release tooling, isolated Microsoft Edge/CDP.

## Global Constraints

- Preserve sender outbox, delivery ledger, receiver batches, rendered proof, session store, command registry, and runtime controller authority.
- Do not add dependencies, content storage, raw interview telemetry, foreground browser activation, or normal-profile mutation.
- No executable tests until all Cycles 71–110 are source-complete.
- The final technical HTML is updated only after exact-commit automated/browser evidence is green.
