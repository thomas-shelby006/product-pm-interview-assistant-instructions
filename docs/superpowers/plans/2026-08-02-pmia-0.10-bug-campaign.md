# PMIA 0.10 Thirty-Cycle Bug Campaign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reproduce and fix thirty concrete defects or invariant violations across the completed PMIA 0.10 control plane and user-facing features.

**Architecture:** Every cycle begins with a regression contract that demonstrates a specific failure. The fix is applied at the existing owner. Cross-cutting audits remain test-only or metadata-only and never become parallel runtime owners.

**Tech Stack:** Manifest V3 JavaScript, Node tests, PowerShell release/smoke tooling, HTML/CSS dashboard, AutoHotkey validation.

## Global Constraints

- Coherence foundation and all ten live-feature cycles must be source-complete before this campaign starts.
- Do not classify file size, naming preference, or speculative cleanup as a bug without a reproduced effect.
- Do not weaken lossless persistence, exact proof, explicit choices, privacy, or release gates to make tests pass.
- Write regression contracts during development; execute at subsystem and final campaign gates.

---

## Block A: Control-plane and decision integrity

### Cycle 1 — Registry/protocol/controller parity
- Test adding, removing, and renaming commands; reject missing owner, missing protocol, duplicate owner, or stale visible control.
- Fix registry generation/audit invalidation and deterministic error reporting.

### Cycle 2 — DOM identity and event reachability
- Reproduce duplicate IDs, stale cached nodes after rerender, and disconnected delegated listeners.
- Enforce unique IDs and event-owner coverage in dashboard validation.

### Cycle 3 — Payload and choice replay safety
- Reproduce malformed payloads, oversized strings, unknown fields, stale choice fingerprints, and replay after resolution.
- Fix command-specific normalization and choice-state compare-and-set behavior.

### Cycle 4 — Operation Guard concurrency
- Reproduce duplicate clicks, timeout followed by late result, disconnect cancellation, journal replay, and session-end races.
- Fix pending-operation lifecycle and idempotent result handling.

### Cycle 5 — Decision Center navigation safety
- Reproduce wrong anchor/view, unavailable recommended action, choice item executed as command, and stale primary ranking.
- Fix action-mode routing and availability projection.

### Cycle 6 — Shortcut/palette/dock/dialog coherence
- Reproduce shortcut conflict, disabled command execution, stale Action Dock action, focus escape, and failed focus return.
- Fix shared registry consumption and focus coordination.

**Primary files:** command registry, dashboard protocol, controller, Decision Center, dashboard event delegation, shortcut bindings, focus coordinator, Action Dock, Choice Workspace.

## Block B: Runtime lifecycle and ownership

### Cycle 7 — Worker suspension during operations
- Suspend the service worker during command, choice, policy preview, and journal commit.
- Restore or reject safely without duplicate mutation.

### Cycle 8 — Page lifecycle recovery
- Reproduce reload, BFCache restore, prerender, freeze, discard, and hidden-window scheduling during active/next batches.
- Fix lifecycle fencing and state rehydration.

### Cycle 9 — Duplicate runtime ownership
- Reproduce duplicate injection, stale lease, owner replacement, healthy duplicate rejection, and generation mismatch.
- Fix registration election and role fencing.

### Cycle 10 — Dashboard reconnect continuity
- Disconnect during pending command, unresolved choice, wizard step, and preview confirmation.
- Restore view/state and fail pending promises exactly once.

### Cycle 11 — Alarm/deadline rehydration
- Reproduce missing alarms, stale generation alarms, overdue deadlines, duplicate alarms, and startup catch-up.
- Fix alarm identity, reconciliation, and bounded immediate catch-up.

### Cycle 12 — Shutdown/crash cleanup
- Reproduce crash after prepare-end, partial cleanup, unresolved outbox, active choice, and orphaned windows.
- Fix transactional continuation and fail-closed end guard.

**Primary files:** background entry, runtime injection fence, registration/owner election, recovery schedule, alarm rehydration, crash resume, session end guard, cleanup journal, dashboard reconnect policy.
## Block C: Lossless transport and receiver mechanics

### Cycle 13 — Sender outbox durability
- Reproduce extension-session write failure, rollback, reload restore, ordered replay, retry-intent loss, and duplicate persistence acknowledgement.
- Fix fail-closed restoration and one-timer ordered replay.

### Cycle 14 — Ledger index/proof durability
- Reproduce index drift, duplicate IDs, tombstone mismatch, unsafe compaction, partial proof, and mismatched batch membership.
- Repair indexes deterministically and preserve actionable ownership.

### Cycle 15 — Sequence gap continuity
- Reproduce out-of-order arrivals, missing sequence retry, buffered reconnect, duplicate stale ACK, and drain failure.
- Fix offer/confirm/NACK continuity and bounded retry.

### Cycle 16 — Receiver credit and fair batching
- Reproduce credit oscillation, oversized accumulation, starvation, failed batch reinsertion, and partition-boundary errors.
- Fix hysteresis, fair scheduling, and exact sequence-safe partitions.

### Cycle 17 — Post-answer policy races
- Reproduce simultaneous answer completion, no-response decision, pause, drain, submit-on-idle, and interrupt confirmation.
- Fix one transaction owner and stale-token rejection.

### Cycle 18 — Composer conflict and route change
- Reproduce manual edit during protected draft, merge/restore/keep transitions, provider route change, and proof reconciliation.
- Preserve manual text and exact member fingerprints without automatic overwrite.

**Primary files:** sender outbox, delivery ledger/index, contiguous sequence buffer, receiver credit, batch planner/partitioner/scheduler, receiver policy/runtime, composer arbiter, proof reconciliation.

## Block D: Provider, storage, and performance

### Cycle 19 — Provider readiness and hidden scheduling
- Reproduce selector fallback exhaustion, capability probation, missing Send control, hidden rAF/timer throttling, and stale composer evidence.
- Fix mutation-first scheduling and stable readiness proof.

### Cycle 20 — Active route transition
- Change provider capability/route while active and next batches exist.
- Freeze provider writes, preserve batches, re-probe, and reconcile without duplicate submission.

### Cycle 21 — Storage transactional safety
- Reproduce quota pressure, failed save, mutated cache, rollback, proven compaction, and critical backpressure.
- Fix atomic cache reset and protected-category accounting.

### Cycle 22 — Snapshot/render correctness
- Reproduce delta-before-full, missed heavy-section update, heartbeat drift, duplicate render, and idle task after session end.
- Fix baselines, section invalidation, scheduler cancellation, and one render owner.

### Cycle 23 — Large-state boundaries
- Exercise 10,000 ledger entries, 1,000 commands, long timelines, virtual list edges, search cache invalidation, and bounded history.
- Fix O(1)/indexed paths and memory budgets without truncating actionable state.

### Cycle 24 — Forecast/clock/SLA truth
- Reproduce backward clocks, insufficient evidence, answer delay mistaken for delivery delay, provider latency spikes, and false repair escalation.
- Fix monotonic time, confidence thresholds, and owning-delay classification.

**Primary files:** provider adapters, selector probes, scheduler yield, route readiness, storage store/accounting, snapshot delta/cache, render scheduler, virtual lists, search indexes, backlog forecast, SLO/clock models.

## Block E: Accessibility, evidence, and release

### Cycle 25 — Keyboard and focus safety
- Traverse every visible control by keyboard, test roving toolbars, dialogs, gesture expiry, Back-to-live, and return focus.
- Fix inaccessible controls and focus ownership.

### Cycle 26 — Visual/accessibility preferences
- Reproduce reduced-motion drift, text-scale overflow, contrast regressions, duplicate live announcements, and narrow-layout clipping.
- Fix system preference resolution, CSS budgets, and announcement coalescing.

### Cycle 27 — Privacy boundaries
- Inject question, answer, setup, clipboard, URL, token, and credential-like values into runtime fixtures.
- Prove support/release bundles contain only allowed metadata and fail closed on leakage.

### Cycle 28 — Responsive/control evidence
- Verify Pilot and Production views at desktop, 320 px, 280 px, and print with every required control reachable and unique.
- Fix overflow, hidden controls, duplicate IDs, and print-only omissions.

### Cycle 29 — Isolated browser release path
- Reproduce swallowed source Send, composer disappearance, Q2/Q3 accumulation, exact proof, 12-check drill, transient provider failure, and cleanup.
- Fix harness/runtime owner based on evidence and preserve external limitations distinctly.

### Cycle 30 — Deterministic final handoff
- Reproduce active-version drift, architecture-budget breach, dirty tree, mismatched commit evidence, missing Production UI, tag/merge/push state, and hash instability.
- Fix release/handoff builders and active documentation.

**Primary files:** accessibility audit/preferences, shortcut/focus modules, dashboard CSS/markup, support bundle, smoke harness, release evidence/handoff, active docs, architecture budget report.
