## Correctness and hardening changes

- Canonical command reachability now audits duplicate DOM IDs, duplicate command registry IDs, duplicate controller owners, missing ARIA targets, and every visible/protocol/controller route.
- Consequential payloads are allow-listed and stale policy previews fail closed.
- Duplicate dashboard operations share one in-flight result.
- Runtime ownership uses generation-safe leases; prerendered, frozen, discarded, and inactive hidden pages cannot own provider writes.
- Alarm schedules deduplicate deterministically and report overdue catch-up.
- Cleanup is transactional and ordered; failed steps require explicit retry.
- Sender outbox attempt persistence, ledger index repair, exact sequence ACK/NACK, receiver-credit hysteresis, starvation promotion, immutable interrupt confirmation, and draft-merge idempotency are covered.
- Provider route changes freeze writes while protected ownership exists.
- Render failures are contained, virtual lists remain bounded, forecasts expose confidence, and monotonic clocks reject stale generations.
- Support bundles recursively remove content-like or credential-like fields and fail closed.
- Release handoff requires clean source, exact commit, automated/browser/Assist/privacy/cleanup evidence, no unresolved ownership, and no push/merge/tag.
